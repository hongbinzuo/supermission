# Supermission Quick Start

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/hongbinzuo/supermission/main/scripts/install.sh | bash
```

## First Time Setup (per project)

```bash
cd your-project
supermission init              # Auto-detects agent CLIs (codex, claude, kiro, kimi, etc.)
supermission pipeline init     # Creates pipeline templates
```

## Daily Use

### One-shot task (simplest)

```bash
supermission quick "Fix the login validation bug"
supermission quick "Add unit tests for auth module" --backend codex
supermission quick "Refactor payment service" --backend claude
```

### Multi-agent pipeline

```bash
# Standard feature: plan → code → test → review
supermission pipeline run feature "Add OAuth2 support"

# Quick bugfix: reproduce → fix → verify
supermission pipeline run bugfix "Fix null pointer in payment"

# Full delivery: plan → code → test → review → deploy
supermission pipeline run deploy "Add rate limiting to API"

# Multiple features at once
supermission pipeline batch feature "Add login" "Add signup" "Add password reset"
```

### Step-by-step (full control)

```bash
supermission new "Add user validation" --validation "bun run test"
supermission plan work-001
supermission approve work-001
supermission run work-001 --backend claude
supermission validate work-001
supermission handoff work-001
```

## Check Status

```bash
supermission board             # Kanban board view
supermission list              # Active work records
supermission status work-001   # Single work status
supermission summary work-001  # Detailed summary
supermission cost work-001     # Token usage & cost estimate
supermission trace work-001    # Event timeline
supermission serve             # Web dashboard at localhost:4000
```

## Team Collaboration

```bash
# Setup team (once)
supermission team init
supermission team add --name "Alice" --role lead
supermission team add --name "Bob" --role developer
supermission team add --name "Claude Worker" --kind agent --role agent --backend claude

# Assign work
supermission new "Fix login bug" --assign bob
supermission assign work-001 --to alice
supermission board --mine              # Show only my work

# Release assignment
supermission release work-001
```

## Runner Configuration

```yaml
# .supermission/runners.yaml (auto-generated by init)
default_backend: auto
fallback_order: [codex, claude, kiro, kimi, gemini]
routing:
  planner-agent: gemini # Cheap, good at planning
  worker-agent: claude # Best at complex coding
  tester-agent: codex # Good at test generation
  reviewer-agent: gemini # Cheap, good at review
```

## Custom Pipelines

Create `.supermission/pipelines/my-pipeline.yaml`:

```yaml
name: my-pipeline
description: My custom workflow
stages:
  - id: research
    role: planner-agent
    prompt: "Research the best approach for this task"
  - id: implement
    role: worker-agent
    prompt: "Implement it following best practices"
  - id: test
    role: tester-agent
    validation: "npm test"
    prompt: "Write and run tests"
  - id: security
    role: reviewer-agent
    prompt: "Review for security issues"
    gate: approve_security
```

Then run: `supermission pipeline run my-pipeline "Your goal"`

## Key Commands Reference

| Command                                   | Purpose                      |
| ----------------------------------------- | ---------------------------- |
| `supermission init`                       | Setup project, detect agents |
| `supermission quick "goal"`               | One-shot end-to-end          |
| `supermission pipeline run <name> "goal"` | Multi-agent pipeline         |
| `supermission board`                      | Kanban view                  |
| `supermission list`                       | List active work             |
| `supermission cost <id>`                  | Token/cost report            |
| `supermission serve`                      | Web dashboard                |
| `supermission team init`                  | Setup collaboration          |
| `supermission runner list`                | Show available agents        |

## File Structure

```
your-project/
└── .supermission/
    ├── runners.yaml           # Agent config
    ├── pipelines/             # Pipeline templates
    │   ├── feature.yaml
    │   ├── bugfix.yaml
    │   └── deploy.yaml
    ├── team.yaml              # Team members (optional)
    ├── policy.yaml            # Security policies (optional)
    └── <work-id>/             # Each task's record
        ├── work.yaml          # Status, goal, assignee
        ├── events.jsonl       # Event timeline
        ├── run.log            # Agent execution log
        ├── validation.log     # Test results
        ├── plan.md            # Plan artifact
        ├── review.md          # Review artifact
        └── handoff.md         # Handoff artifact
```
